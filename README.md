# Customer Shopping Trends Analysis Using SQL

## About This Project
I worked on this project to practice my SQL skills using a real shopping dataset from Kaggle. The dataset has around 3,900 records with information about customers, their purchases, and shopping preferences

I used PostgreSQL and DBeaver to explore the data, check for possible issues, and answer different business questions using SQL.

## Tools I Used

- **PostgreSQL** – To analyze the data
- **DBeaver** – To write and run SQL queries

## What I Did

I worked on 4 phases:

**Phase 1. Data Exploration**

I started by looking at the dataset, checking the number of records, and understanding the columns.

**Phase 2. Data Cleaning Checks**

I checked for missing values, duplicates, extra spaces, and inconsistent data.

**Phase 3. Business Analysis**

I explored total revenue, popular products, customer spending by age and gender, seasonal sales, and shopping preferences.

**Phase 4. Advanced SQL Analysis**

I used CTEs and window functions to rank products, compare revenue across categories, calculate percentages, and find purchases above the average.

## SQL Skills I Practised

`SELECT` · `WHERE` · `GROUP BY` · `HAVING` · `SUM()` · `AVG()` · `CASE WHEN` · CTEs · `RANK()` · `DENSE_RANK()` · `ROW_NUMBER()` · `PARTITION BY`

## Key Findings

*I will add the actual results from my SQL analysis here.*

- **Total revenue:** $233081 USD
- **Highest-revenue category:** Clothing
- **Most frequently purchased product:** Jewellery, Pants, Blouse
- **Interesting customer spending pattern:**
From my SQL analysis, I found that:
- Male customers generated more total revenue than female customers.
- Fall was the season with the highest total revenue.
- Customers aged 65 and above generated the highest revenue among the age groups.
